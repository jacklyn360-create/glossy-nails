# 💅 Glossy Nails

A modern, interactive website for a personal nail business, designed to showcase nail art, inspire clients, generate custom nail designs with AI, and make booking an appointment simple.

## ✨ Overview

**Glossy Nails** is a front-end web experience that brings a nail artist's portfolio and booking experience together in one place.

The site includes:

* 🏠 **Homepage** — Introduction to the Glossy Nails brand and services
* 💅 **Portfolio** — Showcase of completed nail designs
* ✨ **Inspiration Gallery** — Browse nail styles and ideas
* 🤖 **AI Nail Design Generator** — Generate custom nail-design concepts
* 📅 **Booking Page** — Request an appointment
* 🎨 **Responsive Design** — Designed for a polished experience across different screen sizes

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jacklyn360-create/glossy-nails.git
```

### 2. Open the project

```bash
cd glossy-nails
```

### 3. Run the website

Because this project is primarily a front-end website, you can open `index.html` directly in your browser.

For the best development experience, use a local server such as VS Code's **Live Server** extension.

## 🤖 AI Nail Design Generator

The project includes an interactive nail-design generator that allows users to explore custom nail concepts.

The generator is supported by:

* `design-generator.html`
* `test-generator.html`
* `generate_image.py`

The Python script can be used as part of the image-generation workflow.

> **Note:** If the generator relies on an external AI API, make sure API credentials are stored securely and are never committed to GitHub.
